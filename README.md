# fb-clone-website
This is Facebook website clone. I made it during our git tutorial
Features
Facebook-inspired homepage layout
Navigation/header section
User profile section
Posts/feed section
Sidebar navigation
Friends and contacts section
Like, comment, and share UI elements
Responsive website structure
Clean and simple user interface
🛠️ Technologies Used
HTML5 – Used to create the structure of the website
CSS3 – Used for styling and layout
Git – Used for version control
GitHub – Used to store and manage the project online
